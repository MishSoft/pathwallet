# 🚀 PathWallet - AI-Powered Financial Tracker

**PathWallet** is a modern, high-performance personal finance management platform. It empowers users to take full control of their financial life by tracking income, managing expenses, and visualizing long-term savings goals in one sleek interface.



## ✨ Key Features

* **Financial Dashboard:** A comprehensive overview of your total balance, recent transactions, and spending habits.
* **Goal Tracking:** Set specific financial targets (e.g., "Emergency Fund") and track your progress with interactive visual bars.
* **Intelligent Categorization:** Organize transactions into categories like Food, Transport, and Utilities for better insights.
* **Secure Authentication:** Robust user security using **JWT (JSON Web Tokens)** and **HTTP-only cookies** to prevent unauthorized access.
* **Data Privacy & Control:** Complete user autonomy with features to update profiles, change passwords, and permanently delete accounts (GDPR compliant logic).
* **AI Integration (Ready):** Pre-built infrastructure for **Google Gemini AI** to provide personalized financial coaching based on user data.

## 🛠 Tech Stack

* **Frontend:** [Next.js 15](https://nextjs.org/) (App Router), [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/), [Shadcn/UI](https://ui.shadcn.com/)
* **Database:** [Neon (Serverless PostgreSQL)](https://neon.tech/)
* **Backend Logic:** [Node.js](https://nodejs.org/) / Next.js API Routes
* **Security:** [Bcrypt.js](https://github.com/kelektiv/node.bcrypt.js) for password hashing & JWT for session management
